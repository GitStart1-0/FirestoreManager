# Випуски Ноесиса: вересень–листопад 2026

Маніфест: `noesis-autumn-2026.json`.

Конструктор зберігає окремий `journalNumber`: додатний номер звичайного
випуску, від’ємний номер прихованого, 0 — попередній вигляд без номера.
Внутрішній номер документа не змінюється. Приховані випуски не займають
місячну пару «книга + статті» і не потребують місяця публікації.

Існуючі документи 1/2 отримують лише номери −1/−2. Нові документи 3–8 —
шість добірок із номерами 1–6. Це матеріали для майбутніх вікторин,
без створених запитань. У кожній темі статей чотири джерела.

Публікувати разом із клієнтом Android, який підтримує `journalNumber`:
старий клієнт не приховає від’ємні випуски. Скрипт попереднього перегляду,
транзакційного запису і перевірки знаходиться в Android-репозиторії:
`scripts/publish-noesis-autumn.cjs`. Для цієї зміни не потрібне розгортання
Cloud Functions або правил Firebase.
