# LOGICAL_INFERENCE examples

Each JSON file is a complete question document that can be imported into the Logic tab of the constructor.

- `01-singular-deduction.json` - singular first-order inference.
- `02-categorical-syllogism.json` - categorical syllogism.
- `03-propositional-modus-ponens.json` - classical propositional inference.
- `04-relational-transitivity.json` - relational inference.
- `05-no-valid-conclusion.json` - a valid `NO_VALID_CONCLUSION` scenario.

The examples use schema and engine version `1` and are intended both for manual UI testing and for checking Android mapping and evaluation.
