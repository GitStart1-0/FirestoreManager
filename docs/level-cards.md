# Картки тематичних випусків

Оформлення рівнів Ерудита задається в документі рівня, наприклад `erudite/1`, а не в питаннях і не за номером рівня:

```json
{
  "levelCard": {
    "style": "THEMATIC",
    "title": "Шкільні знання",
    "topic": "Базові знання",
    "description": "Перевірте знання, які допомагають розуміти світ.",
    "details": "50 питань · 5 тематичних блоків"
  }
}
```

`THEMATIC` — ідентифікатор дизайну. Будь-які рівні Ерудита з цією позначкою отримують розширену картку. `STANDARD`, відсутнє поле та невідомі ідентифікатори показуються звичайними круглими елементами. Позначку «Тематичний випуск» додає Android мовою інтерфейсу; окремого поля для неї немає. Назва, тема, опис і деталі беруться з документа мовної колекції. Порожні тема та опис приховуються, порожня назва замінюється номером рівня.

У конструкторі відкрийте дані рівня → «Картка рівня · Ерудит», оберіть оформлення й збережіть. Вибір «Звичайний рівень» вимикає тематичну картку. Доступ до рівня, підписка, прогрес і режим проходження визначаються окремо.

Android зберігає ці дані в локальній БД (міграція 33 → 34 без видалення прогресу). Після зміни метаданих потрібне звичайне оновлення списку рівнів через мережу. Старі версії застосунку з демонстраційною карткою ігнорують цей параметр: потрібен новий APK.
