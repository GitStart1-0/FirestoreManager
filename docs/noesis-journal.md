# Ноезис: дані читацького щоденника

Метадані зберігаються в документі рівня `noesis/{levelId}` (для перекладів —
`noesis_{lang}/{levelId}`), а питання — в його підколекції `questions`.

| Поле | Формат | Призначення |
| --- | --- | --- |
| `name` | string | Назва твору; наявне поле рівня |
| `author` | string | Автор; наявне поле рівня |
| `issueMonth` | string, `YYYY-MM` або порожній рядок | Місяць випуску; наприклад `2026-09` |
| `quote` | string, до 1000 символів | Необов’язкова цитата для компактної картки |

У конструкторі виберіть категорію `noesis`, мову та рівень. Заповніть секцію
«Ноезис · Читацький щоденник» і натисніть «Зберегти дані випуску».
Поля також зберігаються під час збереження питання. Порожні значення очищають
відповідні поля. Перемикання рівня завантажує його власні метадані;
збереження недоступне, доки дані не завантажено успішно.

Android показує місяць мовою інтерфейсу. Якщо поле відсутнє або некоректне,
показує номер випуску. Порядок визначається `levelNumber`, прогрес — фактичними
відповідями, доступ — чинними правилами послідовності та `subscriptionTier`.
`issueMonth` є редакційною позначкою, а не датою автоматичної публікації.
Статус проходження не зберігається в цих редакційних полях.

Нові поля кешуються локально. Міграція Android 32 → 33 додає колонки без
видалення відповідей і прогресу. Старі документи працюють без заповнення нових полів.
